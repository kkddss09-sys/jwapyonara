큐알코드에 뭐가 들었나
열기 전에 확인

큐알코드가 찍힌 사진을 고르면 안에 든 링크나 글자를 보여 드립니다.

사진을 골라 주세요
가는 곳:
링크 열기

사진은 내 기기 안에서만 읽히고 어디에도 전송되지 않습니다. 모르는 사람이 보낸 큐알코드의 링크는 가는 곳을 확인하고 여세요.

오늘 시세는 카톡방에서매일 오후 1~6시에 시세표가 올라와요
어떻게 읽나요?
  • 사진에서 큐알코드 모양을 찾아 글자로 바꿉니다.
  • 링크를 바로 열지 않고 어디로 가는지 먼저 보여 줍니다.
  • 읽는 계산에는 공개 프로그램 jsQR(Cosmo Wolfe, Apache 2.0 허락)을 사이트 안에 넣어 씁니다.
  • 'QR Code'는 DENSO WAVE INCORPORATED의 등록 상표입니다.

이렇게 사용하세요

  1. '사진 고르기' 단추를 눌러 큐알코드가 포함된 이미지나 스크린샷 캡처본을 불러옵니다.
  2. 도구가 사진 속 코드를 자동으로 스캔하여 내부에 담긴 웹 링크나 텍스트를 화면에 표시합니다.
  3. 연결되는 목적지 도메인을 미리 확인한 후 안전하다고 판단되면 링크 열기나 복사를 이용합니다.

이럴 때 쓰면 좋아요

모바일 메신저나 이메일, 온라인 커뮤니티에서 받은 출처가 불분명한 큐알코드를 안전하게 검증하고 싶을 때 유용합니다. 카메라로 무심코 찍어 악성 피싱 사이트로 바로 이동되는 위험을 방지하고, 코드 안에 숨겨진 실제 웹 주소나 문구를 사전에 꼼꼼히 점검할 수 있습니다.

용어 쉽게 보기

큐싱(Qshing)
큐알코드와 피싱(Phishing)의 합성어로, 위조된 코드를 스캔하게 유도해 악성 앱을 설치하거나 금융 정보를 탈취하는 전자 금융 사기 수법입니다.
도메인(호스트)
인터넷 웹사이트가 위치한 고유한 인터넷 주소 체계로, 신뢰할 수 있는 정상 기관이나 공식 사이트인지 판별하는 핵심 기준입니다.
오프라인 디코딩
이미지 파일을 외부 서버로 전송하지 않고 사용자의 단말기 웹브라우저 자체 연산만으로 격자 코드를 해석하는 보안 방식입니다.

자주 묻는 질문

카메라로 직접 비추지 않고 갤러리에 저장된 캡처 사진도 읽을 수 있나요?

네, 스마트폰 화면을 캡처한 이미지나 PC에 다운로드된 사진 파일 등 큐알코드가 선명하게 찍힌 이미지라면 무엇이든 파일 선택을 통해 손쉽게 내용을 읽어낼 수 있습니다.

사진을 올리면 외부 서버에 개인 사진이 저장되거나 유출되지 않나요?

본 도구는 업로드된 사진을 외부 서버로 전송하거나 저장하지 않습니다. 모든 판독 작업은 방문자의 브라우저 내부에서만 즉시 실행되므로 개인정보와 중요 사진이 안전하게 보호됩니다.

큐알코드가 잘 인식되지 않을 때는 어떻게 해야 하나요?

사진 속 코드가 지나치게 흐리거나 각도가 심하게 기울어져 있으면 판독이 어려울 수 있습니다. 코드가 화면 중앙에 바르게 오도록 가까이서 선명하게 다시 캡처하거나 촬영해 불러오시면 인식이 원활해집니다.
