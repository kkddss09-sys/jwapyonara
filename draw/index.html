이름은 내 기기 안에서만 쓰이고 어디에도 전송되지 않습니다. 뽑기는 누를 때마다 무작위입니다.

오늘 시세는 카톡방에서매일 오후 1~6시에 시세표가 올라와요
어떻게 뽑나요?
  • 공정한 무작위 추첨: 브라우저의 암호학적 난수 생성 방식(crypto.getRandomValues)을 사용해 모든 참가자가 동일한 확률로 공정하게 추첨됩니다.
  • 중복 없는 비복원 추출: 한 번 당첨된 이름은 다음 순번에서 중복으로 나오지 않습니다.
  • 개인정보 안전: 입력하신 이름은 외부 서버로 전송되거나 저장되지 않으며, 사용자 기기 안에서만 즉시 계산됩니다.

이렇게 사용하세요

  1. 참가자 입력창에 후보자나 참석자 이름을 한 줄에 한 명씩 차례대로 적거나 쉼표로 구분해 입력합니다.
  2. 아래 '뽑을 사람 수'에서 당첨자 또는 발표자로 선정할 인원수를 지정하거나 빠른 선택 버튼(1명, 2명 등)을 누릅니다.
  3. 붉은색 '뽑기' 단추를 누르면 공정하게 추첨된 순위별 당첨자 명단이 즉시 화면에 나타나며, '결과 복사' 버튼으로 채팅방에 공유합니다.

이럴 때 쓰면 좋아요

사무실 점심 식사 당번 정하기, 회식 자리 배치나 커피 쏘기 내기, 동호회 및 스터디 발표 순서 정하기 등 일상 속 공정한 무작위 결정이 필요할 때 좋습니다. 블로그나 SNS 댓글 이벤트 경품 추첨을 진행할 때도 투명하고 조작 없는 비복원 추출 결과를 얻을 수 있습니다. 별도의 가입이나 프로그램 설치 없이 모바일과 PC에서 즉시 활용할 수 있습니다.

알아 두면 좋은 것

암호학적 난수(crypto.getRandomValues)
일반 난수 알고리즘보다 예측이 불가능하고 통계적 균등성이 철저히 보장되는 브라우저 내장 보안 난수 생성 엔진입니다.
비복원 추출
한 번 뽑힌 참가자는 다음 당첨 대상자 명단에서 완전히 제외하여 동일한 사람이 두 번 연속 당첨되지 않도록 보장하는 방식입니다.
클라이언트 단독 실행
입력한 모든 이름과 추첨 연산이 사용자의 단말기 메모리 안에서만 처리되므로 참가자의 개인정보가 외부 서버에 남지 않습니다.

자주 묻는 질문

특정 사람에게 가중치를 주거나 당첨 확률을 조작할 수 있나요?

본 추첨 도구에는 어떠한 인위적 가중치나 조작 기능도 포함되어 있지 않습니다. 입력된 모든 참가자는 수학적으로 완벽히 동일한 확률을 부여받아 공정하게 추첨됩니다.

동명이인이 있을 때는 어떻게 구분하여 입력하나요?

이름이 같은 참가자가 여러 명 있다면 '김철수A', '김철수(마케팅)', '김철수 1'과 같이 괄호나 부서를 덧붙여 고유하게 식별할 수 있도록 적어주시면 혼선 없이 추첨할 수 있습니다.

추첨 결과 목록을 카카오톡이나 단체 메신저로 바로 전송할 수 있나요?

추첨 후 하단에 생성되는 '결과 복사' 단추를 누르면 당첨된 순위와 이름이 깔끔한 텍스트 형식으로 클립보드에 자동 복사됩니다. 대화방 입력창에 그대로 붙여넣어 즉시 공유하실 수 있습니다.
