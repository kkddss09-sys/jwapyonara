💡 한 손 조작 팁: [칠하기]와 [X 표시] 단추로 모드를 바꾸거나, 칸을 길게 누르면 반대 표시가 돼요. 마우스는 우클릭으로 바로 X 표시할 수 있어요.

네모 로직 하는 법
  • 숫자 힌트 규칙: 각 행과 열에 적힌 숫자는 그 줄에 연속해서 칠해야 하는 칸 수입니다.
  • 숫자가 여러 개인 경우: 예컨대 2 1은 2칸을 연속해서 칠한 뒤, 적어도 1칸 이상의 빈칸을 두고 1칸을 칠해야 한다는 뜻입니다.
  • 순서 지키기: 숫자의 순서는 가로줄은 왼쪽에서 오른쪽, 세로줄은 위에서 아래 순서입니다.
  • X 표시 활용: 절대 칠해질 수 없다고 확신하는 칸은 X 표시를 해 두면 남은 칸을 쉽게 찾을 수 있습니다.
  • 틀린 칸 판정: 푸는 도중에는 틀린 칸을 알려주지 않으며, 모든 정답 칸을 정확히 칠했을 때 자동으로 완성 판정이 됩니다.

이렇게 즐기세요

  1. 상단에서 쉬움(5×5), 보통(10×10), 어려움(15×15) 중 원하는 단계를 고릅니다.
  2. 판 크기와 같은 숫자(예: 5×5에서 5)나 큰 숫자부터 먼저 칠하면 실마리를 풀기 쉽습니다.
  3. 양쪽 끝에서 겹치는 칸을 찾아 채워 넣고, 확실하지 않은 칸은 X 표시로 지워 나가세요.
  4. 문제를 빠르게 풀수록 높은 점수를 얻으며, 5문제를 연달아 풀어 누적 최고 점수에 도전해 보세요!
