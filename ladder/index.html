이름은 내 기기 안에서만 쓰이고 어디에도 전송되지 않습니다. 사다리는 탈 때마다 무작위로 새로 그려집니다.

오늘 시세는 카톡방에서매일 오후 1~6시에 시세표가 올라와요
어떻게 사다리를 타나요?
  • 무작위 가로줄: 사다리의 가로줄은 매번 무작위로 놓이며, 인접한 두 가로줄이 겹치지 않도록 배치됩니다.
  • 1:1 매칭: 위에서 아래로 내려오며 만나는 가로줄을 따라 건너가므로 참가자 모두가 겹치지 않고 서로 다른 결과에 닿게 됩니다.
  • 경로 확인: 결과 목록에서 참가자 이름을 누르면 해당 참가자가 내려간 사다리 경로를 빨간 선으로 바로 확인할 수 있습니다.

이렇게 즐기세요

  1. 참가자 이름 입력 칸에 사다리 타기에 참여할 사람들의 이름을 한 줄에 한 명씩 차례대로 적습니다(최소 2명에서 최대 10명까지 지원).
  2. 결과 항목 입력 칸에 당첨, 꽝, 청소 당번, 간식 쏘기 등 원하는 결과 문구를 한 줄에 하나씩 작성합니다. 결과 항목 수가 참가자보다 적으면 빈자리는 자동으로 '꽝'으로 채워집니다.
  3. '사다리 타기' 버튼을 누르면 무작위로 가로줄이 생성되면서 즉시 결과가 추첨됩니다.
  4. 화면 아래 결과 목록에서 특정 참가자 이름을 클릭하면 해당 참가자가 이동한 사다리 경로를 파란 선으로 한눈에 추적해 볼 수 있습니다.

이럴 때 쓰면 좋아요

직장 동료들과 점심 식사 후 커피 내기를 하거나, 모임이나 워크숍에서 발표 순서 및 청소 당번을 정할 때 유용합니다. 친구들끼리 보드게임을 하거나 역할을 나눌 때 누구 하나 불만 없이 모두가 수긍할 수 있는 공정하고 흥미진진한 무작위 추첨이 필요하다면 언제든 간편하게 활용해 보세요.

알아 두면 좋은 것

일대일 대응 추첨
사다리 타기는 수학적으로 시작 지점과 끝 지점이 반드시 하나씩 일대일로 연결되는 치환 구조를 가지고 있어 어떤 경우에도 결과가 중복 배정되지 않습니다.
가로줄의 무작위 배치
서로 인접한 가로줄이 바로 옆에서 연속으로 이어져 교차 오류를 일으키지 않도록 규칙에 맞춰 안전하고 무작위하게 가로선을 배치합니다.
결과 클립보드 복사
'결과 복사' 단추를 누르면 참가자별 매칭 결과 전체가 텍스트 형태로 복사되어 카카오톡 단체 대화방이나 메신저에 바로 공유할 수 있습니다.

자주 묻는 질문

사다리 타기 결과는 조작이나 편향이 없나요?

가로줄은 웹 브라우저가 실행될 때마다 무작위 알고리즘을 통해 매번 완전히 새롭게 생성됩니다. 참가자 위치나 순서에 따른 유불리가 없으며, 모든 참가자가 완전히 동일한 확률 조건 아래에서 공정하게 결과에 도달하도록 설계되었습니다.

입력한 참가자 이름이나 데이터가 서버로 전송되나요?

본 도구는 별도의 회원가입이나 서버 통신 없이 사용자의 웹 브라우저 내부에서만 자바스크립트로 연산됩니다. 따라서 입력하신 참가자 이름이나 내기 항목 등의 개인 데이터는 외부에 전혀 저장되거나 유출되지 않으므로 안심하고 사용하셔도 됩니다.

참가자가 10명을 초과하는 경우에는 어떻게 하나요?

모바일 화면에서의 가독성과 캔버스 선 식별의 명확성을 유지하기 위해 한 화면 최대 인원을 10명으로 제한하고 있습니다. 10명이 넘는 큰 모임에서는 조별로 나누어 1차 사다리를 탄 뒤 대표자끼리 2차 사다리를 타는 토너먼트 방식을 활용해 보세요.
