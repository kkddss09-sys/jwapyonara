갤럭시 단축키·숨은 기능

찾는 일을 적으면 바로 나옵니다. 버튼은 같이 누르는 것과 차례로 누르는 것이 있습니다.

※ 최근 갤럭시(One UI) 기준입니다. 기종과 버전에 따라 메뉴 이름이나 동작이 조금 다를 수 있습니다. 아이폰은 아이폰 단축키에 있습니다.

이렇게 사용하세요

  1. 검색창에 '캡처', '전원', '재시작', '커서' 등 찾고 싶은 동작을 입력하여 해당하는 버튼 조합이나 제스처를 찾습니다.
  2. 측면 버튼과 볼륨 버튼을 '짧게 같이 누르기', '길게 누르기', '연속 두 번 누르기' 등 안내된 타이밍에 맞춰 조작합니다.
  3. 버튼 조작 외에도 화면 쓸어내리기, 스페이스바 드래그 등 유용한 화면 손동작 제스처를 카테고리별로 확인합니다.

이럴 때 쓰면 좋아요

스마트폰 화면이 갑자기 멈추거나 먹통이 되었을 때 서비스 센터에 가지 않고 기기를 강제로 안전하게 재부팅하고 싶을 때 필수적입니다. 또한 웹 서핑 중 긴 웹페이지 전체를 한 장의 사진으로 스크롤 캡처하거나, 긴 문장을 타이핑하다가 오타 난 위치로 키보드 커서를 정밀하게 이동하고 싶을 때 매우 유용합니다.

알아 두면 좋은 것

강제 재시작 (측면 + 볼륨 아래 7초 이상)
터치 화면이 전혀 반응하지 않는 비정상적인 벽돌 현상이나 앱 충돌 멈춤 상황에서 기기의 전원을 안전하게 강제로 껐다 켜는 비상 복구 명령입니다.
스크롤 캡처 (더보기 캡처)
일반 화면 캡처 직후 화면 하단에 뜨는 툴바에서 아래 방향 화살표를 연속으로 눌러 보이지 않는 아래쪽 화면까지 길게 이어 붙여 한 장으로 저장하는 기능입니다.
스페이스바 커서 트랙패드
가상 키보드의 스페이스바를 꾹 누른 채 손가락을 좌우상하로 미끄러뜨리면 마우스 트랙패드처럼 텍스트 커서 위치를 섬세하게 이동할 수 있는 기능입니다.

자주 묻는 질문

측면 버튼을 길게 누르면 전원 메뉴 대신 빅스비나 음성 비서가 켜집니다.

기본 설정 상태에서는 측면 버튼을 길게 누를 때 음성 비서가 호출되도록 지정되어 있을 수 있습니다. 휴대폰 설정 메뉴의 '유용한 기능' 항목 안 '측면 버튼' 설정에서 '길게 누르기' 동작을 '전원 끄기 메뉴'로 변경하시면 이전처럼 편하게 전원 메뉴를 띄울 수 있습니다.

손날 캡처가 자꾸 실패하고 인식이 잘 안 됩니다.

손날 화면 캡처는 손바닥 옆면 전체를 화면 유리에 밀착시킨 상태로 화면 오른쪽 끝에서 왼쪽 끝까지 부드럽게 쓸어 넘겨야 인식됩니다. 만약 자꾸 빗나가거나 번거로우시다면 측면 버튼과 볼륨 아래 버튼을 '동시에 짧게 톡' 누르는 물리 버튼 방식을 추천합니다.

구형 기종이나 보급형 모델에서도 기능이 모두 지원되나요?

운영체제 소프트웨어(One UI) 버전이나 기기 물리 버튼 구조(별도 홈 버튼 유무)에 따라 조작 방법이 약간씩 다를 수 있습니다. 특히 구형 모델의 경우 전원 버튼과 홈 버튼을 함께 누르는 방식일 수 있으므로 기기 설정의 사용설명서를 참고하시기 바랍니다.
