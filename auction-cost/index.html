어떻게 계산했나요?
  • 취득 비용: 낙찰가 × 취득 비용률 (취득세, 지방교육세, 농특세, 채권할인비용 등)
  • 부대비용: 법무 비용 + 명도 비용 + 수리비 + 밀린 관리비 + 이사 비용
  • 총 추가 비용: 취득 비용 + 부대비용
  • 최종 총 소요비용: 낙찰가 + 총 추가 비용
밀린 관리비는 낙찰자가 전부 내야 하나요?

체납 관리비의 승계 범위나 정산 기준은 물건 종류 및 관련 규정에 따라 차이가 있을 수 있으므로 입찰 전 해당 관리사무소나 전문가에게 확인하세요.

명도 비용과 이사비는 의무적으로 줘야 하나요?

이사비 지급 여부와 인도 절차는 해당 사건의 사정을 확인하세요. 강제집행 절차 및 소요 비용은 해당 법원 집행관사무소나 법률 전문가에게 확인하세요.

취득 비용률 4.6%는 어떤 기준인가요?

취득세와 관련 부대비용을 대입해 볼 수 있도록 둔 예시 수치입니다. 실제 취득세율과 부대비용률은 부동산 종류, 보유 주택 수, 취득가액 등에 따라 달라지므로 관할 지자체나 세무 전문가에게 확인하여 직접 입력하세요.

직접 계산해 본 예시

예시 1: 3억 원 낙찰 시 부대비용 계산

입력값: 낙찰가 300,000,000원, 취득 비용률 4.6%, 법무 비용 1,500,000원, 명도 비용 3,000,000원, 수리·인테리어비 10,000,000원, 밀린 관리비(공용부) 2,000,000원, 이사 비용 1,000,000원

계산 과정: 취득 비용(세금 등)은 300,000,000원 × 4.6% = 13,800,000원입니다. 기타 부대비용 합계는 1,500,000원 + 3,000,000원 + 10,000,000원 + 2,000,000원 + 1,000,000원 = 17,500,000원입니다. 추가 비용 합계는 13,800,000원 + 17,500,000원 = 31,300,000원이며, 낙찰가 포함 총비용은 300,000,000원 + 31,300,000원 = 331,300,000원입니다. (낙찰가 대비 약 10.43%)

계산 결과: 추가 비용 합계 31,300,000원, 낙찰가 포함 총비용 331,300,000원 (취득 비용 13,800,000원, 기타 부대비용 합계 17,500,000원)

예시 2: 5억 원 낙찰 시 취득 비용률 1.1%를 입력한 경우

입력값: 낙찰가 500,000,000원, 취득 비용률 1.1%, 법무 비용 1,000,000원, 명도 비용 0원, 수리·인테리어비 5,000,000원, 밀린 관리비(공용부) 0원, 이사 비용 500,000원

계산 과정: 취득 비용은 500,000,000원 × 1.1% = 5,500,000원입니다. 기타 부대비용 합계는 1,000,000원 + 0원 + 5,000,000원 + 0원 + 500,000원 = 6,500,000원입니다. 추가 비용 합계는 5,500,000원 + 6,500,000원 = 12,000,000원이며, 낙찰가 포함 총비용은 500,000,000원 + 12,000,000원 = 512,000,000원입니다. (낙찰가 대비 약 2.4%)

계산 결과: 추가 비용 합계 12,000,000원, 낙찰가 포함 총비용 512,000,000원 (취득 비용 5,500,000원, 기타 부대비용 합계 6,500,000원)

헷갈리기 쉬운 기준과 계산 방식

  • 취득 비용의 반올림: 취득 비용(세금 등)은 '낙찰가 × 취득 비용률 ÷ 100'을 계산한 뒤 1원 단위로 반올림(Math.round)합니다.
  • 0원과 음수 입력 제한: 낙찰가는 0보다 커야 하며, 각 부대비용 항목은 0 이상이어야 정상 계산됩니다. 음수를 입력하면 계산이 중단되고 안내 문구가 나타납니다.
  • 계산에 안 들어가는 비용: 대출 이용 시 발생하는 대출이자 및 근저당 설정비용, 향후 매도 시 발생하는 중개보수 및 양도소득세 등은 계산에 포함되지 않습니다.
  • 관리비 승계 여부 미판별: 계산기는 사용자가 입력한 밀린 관리비 금액을 단순 합산할 뿐 공용부/전유부 승계 여부를 자체 판단하지 않습니다.
