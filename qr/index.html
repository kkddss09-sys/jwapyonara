링크를 큐알코드로
바로 만들기

링크나 글자를 넣으면 큐알코드가 바로 바뀝니다. 아래는 예시이니 바꿔 넣으세요.

큐알코드
0자최대 500자

넣은 내용은 내 기기 안에서만 큐알코드로 바뀌고 어디에도 전송되지 않습니다. 인쇄하거나 보내기 전에 휴대폰 카메라로 한 번 찍어 맞게 열리는지 확인하세요.

오늘 시세는 카톡방에서매일 오후 1~6시에 시세표가 올라와요
어떻게 만드나요?
  • 넣은 글자를 큐알코드 규격에 맞춰 검정과 흰색 칸으로 바꿉니다. 한글도 넣을 수 있습니다.
  • 글자가 길수록 칸이 촘촘해져 카메라가 읽기 어려워집니다. 링크는 짧을수록 좋습니다.
  • 큐알코드 둘레의 흰 여백은 카메라가 읽는 데 필요하니 잘라 내지 마세요.
  • 만든 큐알코드는 기한 없이 쓸 수 있습니다. 다만 링크가 가리키는 곳이 없어지면 열리지 않습니다.
  • 칸을 만드는 계산에는 공개 프로그램 qrcode-generator(Kazuhiko Arase, MIT 허락)를 사이트 안에 넣어 씁니다. 'QR Code'는 DENSO WAVE INCORPORATED의 등록 상표입니다.

이렇게 사용하세요

  1. 큐알코드에 담고 싶은 웹사이트 주소(URL)나 안내 문구를 텍스트 입력 칸에 작성합니다.
  2. 화면에 즉시 생성된 큐알코드 미리보기를 확인하고 용도에 맞는 저장 크기(작게, 보통, 인쇄용)를 고릅니다.
  3. '그림으로 저장' 단추를 눌러 이미지 파일을 기기에 내려받은 뒤 인쇄물이나 웹상에 활용합니다.

이럴 때 쓰면 좋아요

매장 테이블이나 명함, 전단지에 와이파이 연결 주소나 SNS 채널, 홈페이지 링크를 손쉽게 담아 고객에게 전달하고 싶을 때 매우 유용합니다. 모바일 청첩장 링크를 지인들에게 공유하거나 이벤트 페이지 접속을 유도할 때도 긴 주소를 직접 타이핑할 필요 없이 카메라 스캔 한 번으로 연결해 줍니다.

용어 쉽게 보기

QR코드(큐알코드)
흑백 격자무늬 패턴에 디지털 문자 정보를 2차원 매트릭스 형태로 저장하여 빠르게 인식할 수 있게 만든 코드입니다.
인쇄용 해상도
종이나 현수막, 입간판 등에 크게 인쇄해도 모자이크가 깨지거나 테두리가 번지지 않도록 고해상도 픽셀로 생성하는 옵션입니다.
정적 큐알코드
외부 서버를 거치지 않고 입력한 문자열이나 웹 주소 원본이 코드 격자 안에 그대로 새겨져 유효기간 없이 영구적으로 쓸 수 있는 코드입니다.

자주 묻는 질문

만들어진 큐알코드에 사용 기한이나 만료일이 있나요?

본 도구로 생성된 큐알코드는 별도의 외부 중개 서버를 거치지 않고 입력하신 정보 자체가 코드 안에 직접 저장되는 방식입니다. 따라서 중간에 코드가 만료되거나 차단되는 일 없이 연결된 원래 웹페이지가 살아있는 한 영구적으로 작동합니다.

인쇄물에 넣을 때는 어떤 크기를 선택하는 것이 좋나요?

명함이나 소형 스티커는 '보통(800픽셀)', 입간판이나 포스터, 리플릿 인쇄물에는 '크게(1600픽셀)' 옵션을 추천합니다. 인쇄 후에는 테두리의 흰색 여백(여백 구역)이 잘려 나가지 않아야 카메라가 빠르고 정확하게 인식합니다.

입력한 개인 연락처나 주소가 외부로 유출되지 않나요?

모든 생성 처리는 방문자의 웹브라우저 기기 내부 메모리에서만 순수하게 이루어지며 외부 데이터베이스로 전송되지 않습니다. 안심하고 개인 SNS 링크나 연락처 텍스트를 변환해 사용하셔도 됩니다.
