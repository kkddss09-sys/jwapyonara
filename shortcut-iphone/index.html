아이폰 단축키·숨은 기능

찾는 일을 적으면 바로 나옵니다. 버튼은 같이 누르는 것과 차례로 누르는 것이 있습니다.

※ 홈 버튼이 없는 아이폰(페이스 아이디 모델) 기준입니다. 홈 버튼이 있는 모델은 캡처가 "측면(또는 상단) 버튼 + 홈 버튼"입니다. 갤럭시는 갤럭시 단축키에 있습니다.

이렇게 사용하세요

  1. 검색창에 '캡처', '재시작', '뒷면 탭', '되돌리기' 등 필요한 동작을 입력하여 실행 방법을 찾습니다.
  2. 측면 버튼과 볼륨 버튼 조합의 순서와 누르는 시간(짧게 누르기, 길게 누르기, 순차 입력)을 확인하여 기기를 조작합니다.
  3. 화면 상단 탭, 스페이스바 트랙패드, 세 손가락 제스처 등 상황별 편리한 손동작을 익혀 적용합니다.

이럴 때 쓰면 좋아요

화면 터치가 먹히지 않고 앱이 멈췄을 때 당황하지 않고 안전하게 강제 재부팅을 진행하고 싶을 때 매우 유용합니다. 긴 웹 서핑 후 화면 맨 위로 순식간에 올라가고 싶거나, 기기 뒷면을 손가락으로 톡톡 두드려 스크린샷을 찍는 등 일상 속에서 아이폰을 훨씬 편리하고 스마트하게 다루고 싶을 때 활용해 보세요.

알아 두면 좋은 것

강제 재시동 (볼륨 위 → 볼륨 아래 → 측면 길게)
기기가 먹통이 되었을 때 볼륨 올리기 버튼을 톡, 볼륨 내리기 버튼을 톡 누른 뒤 화면에 사과 로고가 뜰 때까지 측면 전원 버튼만 길게 누르는 비상 복구법입니다.
뒷면 탭 (Back Tap)
아이폰 뒷면을 두 번 또는 세 번 가볍게 두드리는 충격 센서를 감지하여 스크린샷 캡처, 손전등, 카메라 등의 기능을 즉시 실행하는 손쉬운 사용 기능입니다.
상단바 터치 (맨 위로 스크롤)
사파리 웹페이지나 인스타그램, 카카오톡 등 긴 목록을 읽다가 화면 최상단 시간 표시 영역을 가볍게 톡 터치하면 한 번에 맨 위로 스크롤됩니다.

자주 묻는 질문

전원을 끄려고 버튼을 누르고 있었는데 경보음이 울립니다.

측면 버튼과 볼륨 버튼을 길게 누르고 있으면 '밀어서 전원 끄기' 슬라이더가 뜹니다. 이때 손을 떼지 않고 계속 5초 이상 누르고 있으면 비상 긴급 구조 요청(SOS) 카운트다운이 시작되므로, 화면에 슬라이더가 나타나는 즉시 버튼에서 손을 떼셔야 합니다.

뒷면 탭 기능은 어디서 켜고 설정하나요?

아이폰의 '설정' 앱으로 들어가서 '손쉬운 사용' → '터치' → 맨 아래쪽의 '뒷면 탭' 메뉴를 선택하시면 됩니다. 여기서 '이중 탭'과 '삼중 탭' 각각에 스크린샷, 손전등, 제어 센터 등 원하는 동작을 자유롭게 지정할 수 있습니다.

타이핑 중 글자를 잘못 지웠을 때 되살리는 제스처가 있나요?

화면에 세 손가락을 동시에 대고 왼쪽으로 가볍게 쓸어 넘기면 방금 실행한 동작이 취소(Undo)됩니다. 반대로 세 손가락으로 오른쪽으로 쓸면 다시 실행(Redo)되며, 기기를 살짝 흔드는 '흔들어서 실행 취소' 기능도 기본 지원됩니다.
