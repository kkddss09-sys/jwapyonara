글자 수 세기
공백 포함·제외 바로 확인

글을 적거나 붙여 넣으면 글자 수, 단어 수, 줄 수, 용량을 바로 셉니다. 아래 글은 예시이니 바꿔 넣으세요.

띄어쓰기 포함 0자
띄어쓰기 제외 0자 · 0단어

0개

※ 넣은 글은 내 기기 안에서만 세고 어디에도 전송되지 않습니다.

어떻게 계산했나요?
  • 띄어쓰기 포함: 공백, 줄바꿈, 특수문자를 포함한 전체 글자 수입니다. 이모지(😀 등)도 한 글자로 정확히 셉니다.
  • 띄어쓰기 제외: 띄어쓰기, 탭, 줄바꿈을 뺀 순수 글자 수입니다. 자기소개서나 과제 제출 시 유용합니다.
  • 낱말(단어) 수: 빈칸으로 나눈 단어 덩어리의 개수입니다.
  • 줄 수: 줄바꿈을 기준으로 나눈 총 줄 수입니다 (글이 비어 있으면 0줄).
  • 용량: 표준 UTF-8 기준 바이트 수입니다. 영문·숫자는 1바이트, 한글은 3바이트, 이모지는 4바이트로 계산됩니다.

이렇게 사용하세요

  1. 입력 창에 직접 문장을 타이핑하거나, 문서 프로그램에서 복사한 텍스트를 붙여넣습니다.
  2. 입력과 동시에 공백 포함 글자 수, 공백 제외 글자 수, 단어 수, 줄 수, UTF-8 바이트 용량이 실시간 집계됩니다.
  3. 다른 글을 새로 측정하고 싶을 때는 우측 하단의 '모두 지우기' 버튼을 눌러 입력창을 깨끗이 비웁니다.

이럴 때 쓰면 좋아요

취업 준비생의 입사 지원서 자기소개서 작성, 대학 과제 및 논문 초록 제출, 블로그 원고 작성 시 분량 제한을 맞출 때 매우 유용합니다. 공공기관 민원 제기나 포털 사이트 글자 수 규격에 맞추어 문장을 다듬을 때도 필수적입니다. 또한 단어 수와 줄 수, 데이터 전송에 쓰이는 바이트 용량까지 한자리에서 파악할 수 있어 코딩 및 웹 데이터 작업에도 편리합니다.

용어 쉽게 보기

공백 포함 글자 수
띄어쓰기, 탭, 엔터(줄바꿈), 특수문자, 숫자, 한글, 영문을 모두 각각 1글자로 인정하여 합산한 전체 문자 개수입니다.
공백 제외 글자 수
문장 사이에 들어간 스페이스 공백과 줄바꿈 문자를 제외하고 순수하게 내용이 적힌 글자만 세는 수치로, 자소서 심사의 표준 지표입니다.
UTF-8 바이트
컴퓨터 시스템이 문자를 저장하는 용량 단위로, 영문과 숫자는 1바이트, 한글은 3바이트, 특수 기호나 이모지는 최대 4바이트를 차지합니다.

자주 묻는 질문

입력한 글이나 자기소개서 내용이 서버로 유출되지는 않나요?

본 글자 수 세기 도구는 사용자의 PC나 스마트폰 브라우저 내부에서만 자바스크립트로 즉각 계산합니다. 입력된 텍스트는 어떠한 외부 서버로도 전송되거나 저장되지 않으므로 중요한 문서나 개인적인 글도 안심하고 측정하실 수 있습니다.

채용 사이트의 글자 수와 왜 1~2자 차이가 날 수 있나요?

각 채용 사이트나 원서 접수 프로그램마다 줄바꿈(엔터) 문자를 1글자로 보는지 2글자(CR+LF)로 보는지, 혹은 공백 처리 규칙에 따라 미세한 차이가 발생할 수 있습니다. 마감 직전 제출 시에는 허용 한도보다 10~20자 정도 여유를 두고 작성하시는 것을 권장합니다.

이모티콘이나 특수문자도 글자 수에 올바르게 포함되나요?

네, 표준 자바스크립트 문자열 분해 방식을 적용하여 그림 이모지(😀 등)나 특수 기호도 정확하게 1문자로 인식하여 계산합니다. 다만 바이트 용량에서는 이모지가 일반 글자보다 더 많은 용량을 차지합니다.
