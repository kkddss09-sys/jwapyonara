모든 순서 생성과 판정은 기기 안에서만 실행되며 외부로 데이터를 보내지 않습니다.

하는 법
  • 목표: 라운드가 진행될 때마다 하나씩 길어지는 불빛의 순서를 완벽하게 기억해 똑같이 누르는 게임입니다.
  • 진행 순서: 컴퓨터가 먼저 색깔들을 깜빡여 순서를 보여줍니다. 깜빡임이 끝나고 '내 차례'가 되면 동일한 순서로 버튼을 누릅니다.
  • 성공과 탈락: 순서를 끝까지 맞히면 다음 라운드로 올라가고, 하나라도 순서가 틀리면 게임이 종료됩니다.
