크롬 단축키

찾는 일을 적으면 바로 나옵니다. 키를 같이 누르면 됩니다.

※ 윈도우 기준입니다. 맥에서는 Ctrl 대신 ⌘(Command)를 누르면 대부분 같습니다. 엣지 브라우저에서도 거의 같습니다. 컴퓨터 전체 단축키는 윈도우 단축키에 있습니다.

이렇게 사용하세요

  1. 상단 검색창에 '닫은 탭', '시크릿', '기록', '확대' 등 원하는 작업이나 단어를 입력하여 빠르게 단축키를 검색합니다.
  2. 필요한 단축키를 확인한 뒤 키보드에서 해당 키들을 동시에 또는 순서대로 누릅니다.
  3. 카테고리 칩 버튼을 클릭하면 탭·창 관리, 페이지 제어, 다운로드 및 방문 기록 등 묶음별로 모아볼 수 있습니다.

이럴 때 쓰면 좋아요

웹 서핑 중 중요한 탭을 실수로 닫아버려 당황했을 때나, 수많은 탭 사이를 마우스 없이 번개처럼 이동하고 싶을 때 매우 유용합니다. 주소창 입력, 페이지 내 특정 단어 검색, 글씨 크기 조절 등을 키보드만으로 능숙하게 다루어 업무 속도와 인터넷 서핑 효율을 크게 끌어올리고 싶을 때 참고해 보세요.

알아 두면 좋은 것

Ctrl + Shift + T (닫은 탭 복구)
방금 전 실수로 닫은 브라우저 탭을 즉시 되살려주는 마법 같은 단축키로, 여러 번 누르면 닫힌 순서의 역순으로 계속 복원됩니다.
시크릿 창 (Ctrl + Shift + N)
방문 기록, 쿠키, 사이트 데이터, 검색어 기록을 컴퓨터에 남기지 않고 웹을 탐색할 수 있는 비공개 브라우징 모드입니다.
강력 새로고침 (Ctrl + F5)
컴퓨터에 저장된 임시 캐시 파일을 완전히 무시하고 웹 서버로부터 최신 웹페이지 코드를 다시 불러오는 명령입니다.

자주 묻는 질문

애플 맥(Mac) 컴퓨터에서도 이 단축키들이 그대로 작동하나요?

맥OS 환경에서는 대부분의 윈도우 Ctrl 키 대신 커맨드(⌘, Command) 키를 사용하시면 거의 동일하게 작동합니다. 예를 들어 닫은 탭을 다시 열 때는 Command + Shift + T, 새 탭은 Command + T를 누르시면 됩니다.

네이버 웨일이나 마이크로소프트 엣지 브라우저에서도 쓸 수 있나요?

네, 마이크로소프트 엣지, 네이버 웨일, 브레이브 등 크로미움 기반의 웹 브라우저들은 대부분 크롬과 동일한 표준 단축키 체계를 공유하므로 그대로 사용하실 수 있습니다.

단축키가 갑자기 작동하지 않을 때는 어떻게 해야 하나요?

한글/영문 입력기(IME) 상태에 따라 일부 키 조합이 글자 조합 모드로 인식되거나, 다른 백그라운드 프로그램(화면 캡처 앱, 메신저 등)이 해당 키를 글로벌 단축키로 선점했을 때 충돌이 발생할 수 있으니 확인해 보시는 것이 좋습니다.
