어떻게 계산했나요?
  • 배당 순위 숫자가 작은 채권자부터 우선하여 배당합니다.
  • 동일한 순위의 채권자들은 남은 배당금 범위에서 각자의 채권액 비율대로 공평하게 안분(반올림) 배당합니다.
  • 배당받지 못한 잔액은 부족액으로 표시하며, 모든 순위 배당 후 잔여금이 있으면 남은 돈으로 표시합니다.
자주 묻는 질문: 배당 순위는 어떻게 정해지나요?

실제 배당 순위와 배당 재원은 해당 사건의 배당표와 전문가에게 확인하세요.

자주 묻는 질문: 같은 순위 채권자가 여러 명이면 어떻게 나누나요?

배당할 잔여 금액이 동일 순위 채권자들의 채권 총액보다 적을 경우, 각 채권자의 청구 금액 비율에 비례하여 안분 배당합니다. 남은 돈이 전액을 충당하기에 충분하다면 각각 전액을 배당받습니다.

자주 묻는 질문: 순위를 적지 않으면 어떻게 처리되나요?

입력란에 순위를 따로 입력하지 않으면 위에서부터 작성된 줄 번호 순서(1, 2, 3...)대로 순위가 지정됩니다. 특정 순위로 지정하려면 세 번째 항목에 순위 숫자를 적어 주세요.

직접 계산해 본 예시

예시 1: 3명 채권자의 순차 배당 (5억 원 배당금)

입력값: 배당할 돈 500,000,000원
채권자 목록:
가 은행, 300000000, 1
나 세입자, 250000000, 2
다 채권자, 100000000, 3

계산 과정:
· 1순위(가 은행): 청구액 300,000,000원 전액 배당 (남은 배당금: 500,000,000 - 300,000,000 = 200,000,000원, 부족액: 0원)
· 2순위(나 세입자): 청구액 250,000,000원 중 잔여 200,000,000원 배당 (남은 배당금: 0원, 부족액: 250,000,000 - 200,000,000 = 50,000,000원)
· 3순위(다 채권자): 남은 배당금이 없으므로 0원 배당 (부족액: 100,000,000원)
· 배당 후 남은 돈은 0원입니다.

계산 결과: 총 500,000,000원 배당 완료 (가 은행 300,000,000원 배당, 나 세입자 200,000,000원 배당, 다 채권자 0원 배당, 배당 후 남은 돈 0원)

예시 2: 2순위 채권자 2명의 안분 배당 (2억 원 배당금)

입력값: 배당할 돈 200,000,000원
채권자 목록:
A 은행, 100000000, 1
B 카드, 150000000, 2
C 캐피탈, 50000000, 2

계산 과정:
· 1순위(A 은행): 청구액 100,000,000원 전액 배당 (남은 배당금: 100,000,000원)
· 2순위(B 카드, C 캐피탈): 2순위 총 청구액은 150,000,000원 + 50,000,000원 = 200,000,000원입니다. 남은 배당금 100,000,000원을 채권 비율대로 안분 배당합니다.
- B 카드: 100,000,000 × (150,000,000 ÷ 200,000,000) = 75,000,000원 배당 (부족액: 75,000,000원)
- C 캐피탈: 100,000,000 × (50,000,000 ÷ 200,000,000) = 25,000,000원 배당 (부족액: 25,000,000원)
· 배당 후 남은 돈은 0원입니다.

계산 결과: 총 200,000,000원 배당 완료 (A 은행 100,000,000원 배당, B 카드 75,000,000원 배당, C 캐피탈 25,000,000원 배당, 배당 후 남은 돈 0원)

헷갈리기 쉬운 기준과 계산 방식

  • 동순위 안분 계산과 반올림: 동일 순위 채권자의 청구액 합계가 잔여 배당금보다 클 경우 비율대로 나누며 원 단위로 반올림(Math.round)합니다. 채권자별 배당액을 각각 반올림하므로 표시된 배당액 합계가 입력한 배당금과 다를 수 있습니다.
  • 순위 미지정 시 자동 처리: 채권자 입력 시 세 번째 항목인 순위를 생략하면 위쪽 줄부터 차례대로 1순위, 2순위, 3순위로 자동 부여됩니다.
  • 경매비용 사전 공제 필요: 이 계산기는 입력된 '배당할 돈'을 그대로 배분합니다. 실제 법원 경매에서는 집행비용 등이 먼저 공제되므로 공제 후 실제 배당 재원을 입력해야 합니다.
  • 법적 권리순위 자동 판단 불가: 계산기는 확정일자나 근저당 설정일, 대항력 유무를 판별하지 않으며, 사용자가 지정한 순위 번호에 따라서만 순차 배분합니다.
