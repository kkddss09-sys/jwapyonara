나는 컴퓨터가 처음이야. 바탕화면의 'AI연습' 폴더를 이 프로그램에서 고르고 싶어. 먼저 내가 윈도우인지 맥인지 물어봐. 그다음 칸과 화살표 그림으로 알기 쉽게, 한 번에 한 단계씩 설명해 줘. 다른 폴더는 건드리지 말아 줘.

1단계 그림으로 보기 2단계 다음 할 일 복사 도움말 막혔을 때 화면 찍기 부탁 글 부탁 글 만들기

🪄 2단계: "다음 할 일 1·2·3·4" 규칙 복사하기

AI가 답변 끝에 다음에 하면 좋은 일을 1, 2, 3, 4 번호로 콕 집어 알려 주고, 숫자만 보내면 이어서 척척 일해 주는 편리한 규칙이에요!

📸 막혔을 때: 화면 찍어서 AI에게 보여 주기

설치하다가 알 수 없는 창이 뜨거나 무엇을 눌러야 할지 모를 때는 화면을 캡처해서 AI에게 질문해 보세요.

윈도우 (Windows)

1. 키보드에서 윈도우 키(⊞) + Shift + S 를 동시에 눌러요.
2. 마우스로 물어보고 싶은 화면 부분을 네모 모양으로 끌어요.
3. AI 대화 글 칸을 누르고 Ctrl + V 로 붙여 넣어요.
4. "이 화면에서 다음에 뭘 눌러?"라고 보내면 AI가 알려 줘요!

맥 (macOS)

1. 키보드에서 Command(⌘) + Control(⌃) + Shift(⇧) + 4 를 동시에 눌러요.
2. 마우스로 물어보고 싶은 화면 부분을 네모 모양으로 끌어요.
3. AI 대화 글 칸을 누르고 Command(⌘) + V 로 붙여 넣어요.
4. "이 화면에서 다음에 뭘 눌러?"라고 보내면 AI가 알려 줘요!

🗨️ 화면을 보낸 뒤, 이렇게 말해 보세요

화면 그림을 붙여 넣고, 아래 말 하나를 복사해서 함께 보내요. ( ) 안은 내 말로 바꿔요. 순서를 섞거나 한 줄 덧붙여도 좋아요.

좋은 부탁 = ① 무엇을 하고 싶은지 + ② 지금 화면 + ③ 원하는 모양 예: "초대장을 만들고 싶어. 이 화면에서 막혔어. 글자는 크게, 색은 밝게 해 줘."
