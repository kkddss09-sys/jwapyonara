AI로 움직이는 글자 영상 만들기

어려운 전문 편집 도구 없이, 인공지능에게 말로 시켜 웹 코드를 만들고 화면 녹화로 글자 영상을 완성하는 초보자 방법입니다.

궁금한 AI 사용법, 카톡방에서 같이 물어보세요
📌 세 줄 요약
  • 말로 만드는 움직임: 클로드 같은 AI에게 만들고 싶은 글자와 움직임을 설명하면 웹 화면 코드를 작성해 줍니다.
  • 창에서 바로 확인: 클로드에 아티팩트를 요청해 미리보기를 열고 마음에 들 때까지 대화로 고칠 수 있습니다.
  • 기본 기능으로 녹화: 외부 프로그램 설치 없이 컴퓨터나 스마트폰에 내장된 화면 녹화 도구로 영상을 저장합니다.
1

원하는 글자와 움직임 말로 요청하기

인공지능 대화창에 접속하여 로그인한 뒤 새 대화를 시작합니다(아티팩트는 기본 및 유료 플랜에서 이용할 수 있어요).

영상에 넣을 글귀와 원하는 배경 색상, 글자가 나타나는 방식(천천히 커지기, 위로 떠오르기 등)을 설명합니다.

클로드에 '움직이는 웹 화면을 아티팩트로 만들어 보여줘'라고 요청하면 대화 옆 아티팩트 창에서 미리보기를 열 수 있습니다.

💡 첫 번째 부탁 예시
어두운 남색 배경 중앙에 '오늘 하루도 수고하셨습니다'라는 노란색 큰 글자가 부드럽게 커지면서 나타나는 움직이는 웹 화면을 아티팩트로 만들어 미리보기로 보여줘.
2

대화창 옆 별도 창에서 움직임 확인하기

클로드에 아티팩트로 만들어 보여달라고 요청한 뒤 생성된 아티팩트의 미리보기를 엽니다(화면 모습은 기기나 버전에 따라 다를 수 있어요).

별도의 프로그램을 설치하거나 복잡한 설정을 거치지 않아도 브라우저 안에서 글자가 움직이는 모습을 직접 볼 수 있습니다.

글자 크기나 배치, 움직이는 속도가 눈에 잘 들어오는지 꼼꼼하게 살펴봅니다.

💡 움직임 속도 조절 부탁 예시
글자가 너무 빠르게 지나갑니다. 글자가 서서히 나타나는 시간을 3초로 천천히 늘려주고, 글자 아래에 작은 흰색 글씨로 '편안한 밤 되세요'를 추가해줘.
3

마음에 들 때까지 대화로 고쳐보기

원하는 디자인이 나올 때까지 코드를 직접 고칠 필요 없이 대화로 추가 요청을 남깁니다.

"글자 색을 흰색으로 바꿔줘", "배경에 은은한 별빛 효과를 넣어줘"처럼 편안하게 말씀하시면 됩니다.

수정 요청에 대한 생성이 끝나면 미리보기가 갱신되어 바뀐 결과를 바로 보여줍니다.

💡 디자인 변경 부탁 예시
배경을 밤하늘처럼 짙은 남색으로 바꾸고, 글자가 나타난 뒤에 부드럽게 반짝이는 효과를 넣어줘. 스마트폰 화면 비율 세로형에 맞춰 구성해줘.
4

기본 화면 녹화 기능 켜기

외부 유료 생성 서비스를 쓰지 않고 운영체제에 내장된 기본 녹화 기능을 사용합니다.

윈도우는 기본 캡처 도구의 비디오 녹화 기능을 켜고, 맥은 스크린샷 기록 도구를 엽니다.

스마트폰은 상단 빠른 설정(안드로이드)이나 제어 센터(아이폰)에서 화면 녹화 버튼을 준비합니다.

💡 전체 화면 표시 부탁 예시
화면을 녹화하기 전에 불필요한 테두리나 버튼을 숨기고, 움직이는 글자 부분만 화면 중앙에 꽉 차게 보이도록 깔끔하게 화면을 다듬어줘.
5

컴퓨터와 휴대전화 화면 녹화하고 저장하기

컴퓨터에서는 녹화 도구에서 녹화할 사각형 영역을 선택한 뒤 녹화 시작 버튼을 누릅니다.

휴대전화에서는 상단 빠른 설정이나 제어 센터에서 화면 녹화를 바로 시작합니다.

애니메이션이 시작되고 끝날 때까지 화면을 담은 뒤 정지 버튼을 누르고, 녹화 후 저장 위치와 파일 형식을 기기에서 확인합니다.

💡 반복 재생 부탁 예시
애니메이션이 멈추지 않고 5초 주기로 계속 반복해서 움직이도록 반복 설정을 넣어줘. 처음과 끝이 자연스럽게 이어지게 다듬어줘.
⚠️ 꼭 지켜야 할 두 가지 안전 수칙
  • 기밀 및 개인정보 입력 금지: 검토자에게 공개되어서는 안 되는 정보나 머신러닝 학습 개선에 쓰이면 안 되는 기밀 정보는 입력하지 마세요. 주민등록번호, 계좌번호, 비밀번호, 집 주소, 가족 이름 등 민감한 개인정보는 프롬프트에 넣지 않습니다.
  • 생성형 AI 결과 비판적 검토: 생성형 AI 도구에서 얻는 대답이나 코드는 틀릴 수 있으므로 비판적으로 생각하고 사실 확인이 필요합니다. 화면 녹화 전 글자 표기나 움직임에 어색한 부분이 없는지 직접 확인하세요.
💻

운영체제별 기본 화면 녹화 도구 안내

사용하시는 기기 종류에 따라 기본 내장 녹화 도구를 여는 방법에 차이가 있습니다(기기·버전에 따라 다를 수 있어요). 녹화 후 저장 위치와 파일 형식은 기기에서 확인하세요.

Windows PC (컴퓨터)
캡처 도구 비디오 녹화

시작 메뉴에서 '캡처 도구'를 열고 비디오 녹화 모드를 선택한 뒤 녹화할 화면 사각형 영역을 선택하여 녹화합니다.

Apple Mac (컴퓨터)
스크린샷 / QuickTime

스크린샷 도구 또는 QuickTime Player를 실행하여 화면 전체 또는 선택 영역을 비디오로 기록합니다.

삼성 갤럭시 / 안드로이드
상단 빠른 설정 화면 녹화

화면 상단에서 아래로 두 번 스와이프하여 빠른 설정 창에서 '화면 녹화' 아이콘을 찾아 시작합니다.

애플 아이폰 (iOS)
제어 센터 화면 기록

제어 센터를 열고 둥근 모양의 '화면 기록' 단추를 탭하여 사운드와 함께 화면을 녹화합니다.
