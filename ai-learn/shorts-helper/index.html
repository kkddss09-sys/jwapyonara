챗GPT로 나만의 쇼츠 대본 도우미 웹페이지 만들기

프로그래밍 문법을 배우지 않고도, 챗GPT에게 원하는 모양을 요청하여 내 컴퓨터에서 작동하는 대본 작성 도우미 한 장을 만드는 순서입니다.

궁금한 AI 사용법, 카톡방에서 같이 물어보세요
📌 세 줄 요약
  • 원하는 화면 요청: 챗GPT에게 주제를 넣으면 부탁 글이 만들어지는 HTML 한 장 코드를 써달라고 구체적으로 요청합니다.
  • 코드 복사와 저장: 생성된 코드 블록 상단의 복사 단추를 누르고 메모장에 붙여넣은 뒤 영문 이름에 점 html을 붙여 저장합니다.
  • 브라우저로 열기: 저장한 파일을 더블클릭하여 크롬이나 엣지 창으로 열면 나만의 대본 도우미 화면이 실행됩니다.
1

챗GPT 접속 및 기본 화면 구조 요청하기

컴퓨터 웹 브라우저를 열고 챗GPT 공식 사이트에 접속하여 로그인합니다.

인공지능에게 요청할 때는 작업 내용과 필요한 조건을 구체적으로 제시해야 원하는 결과에 가까워집니다.

초보자용으로 별도의 복잡한 설치 없이 브라우저에서 바로 열리는 단일 HTML 파일로 작성해달라고 명시합니다.

💡 첫 번째 웹페이지 요청 부탁 예시
안녕하세요! 코딩 지식이 없는 초보자입니다. 내 컴퓨터 웹 브라우저에서 바로 열 수 있는 쇼츠 대본 도우미 웹페이지 한 장을 만들고 싶습니다. 다른 추가 파일 없이 HTML 파일 하나 안에 스타일과 자바스크립트가 모두 포함된 코드를 작성해줘.
2

입력칸과 복사 기능 구체적으로 다듬기

원하는 웹페이지의 세부 기능과 구성을 하나씩 짚어서 추가 요청을 보냅니다.

주제를 입력하는 칸, 대본 요청 글을 만드는 생성 단추, 그리고 완성된 문장을 클립보드에 담아주는 복사 단추를 요청합니다.

글자 크기를 큼직하게 키우고 어두운 배경에 밝은 글씨로 초보자가 보기 편하게 만들어달라고 요청합니다.

💡 화면 구성과 단추 추가 부탁 예시
앞서 요청한 대본 도우미 화면을 세 가지 요소로 구성해줘. 첫째, 다룰 주제를 입력하는 넓은 입력창. 둘째, 40초 분량 쇼츠 대본 프롬프트를 조립해주는 생성 단추. 셋째, 완성된 결과 글을 한 번에 복사할 수 있는 복사 단추입니다. 50대 사용자가 보기 편하도록 글씨를 큼직하게 키우고 깔끔하게 다듬어줘.
3

챗GPT 답변에서 코드 블록 복사하기

챗GPT가 완성된 코드를 제시하면 일반 대화문과 분리된 별도의 코드 블록 상자에 담겨 나옵니다.

코드 블록 상단에 표시되는 Copy code(코드 복사) 단추를 누르면 전체 내용이 한 번에 복사됩니다.

마우스로 본문을 길게 드래그할 필요 없이 상단 단추를 한 번 누르면 빠짐없이 클립보드에 저장됩니다.

💡 코드 오류 수정 및 안내 부탁 예시
작성해 준 코드 블록 상단의 복사 단추를 눌러 준비했습니다. 혹시 복사 버튼을 눌렀을 때 화면에 복사 완료 알림 문구가 2초간 떴다 사라지는 기능을 추가하려면 어느 줄을 수정해야 하는지 초보자 눈높이로 알기 쉽게 설명해줘.
4

메모장에 붙여넣고 html 확장자로 저장하기

윈도우 작업표시줄 검색창에서 메모장을 찾아 실행한 뒤 빈 화면에 붙여넣기(단축키 Ctrl + V)를 합니다.

상단 메뉴에서 파일 > 다른 이름으로 저장을 선택합니다.

파일 형식을 모든 파일(*.*)로 변경하고, 파일 이름 끝에 반드시 .html을 붙여 입력합니다.

한글이 깨지지 않도록 하단의 인코딩 항목이 UTF-8로 되어 있는지 확인한 뒤 저장 단추를 누릅니다.

💡 메모장 저장 시 한글 인코딩 확인 부탁 예시
메모장에서 코드를 저장할 때 인코딩을 UTF-8로 지정하는 방법과 파일 확장자를 .html로 바르게 입력하는 방법을 컴퓨터 초보자가 헷갈리지 않게 세 줄로 요약해줘.
5

웹 브라우저로 열어 대본 요청 글 만들기

바탕화면이나 폴더에 저장된 html 파일을 마우스로 더블클릭하면 평소 쓰는 인터넷 브라우저 창에서 열립니다.

주제 입력칸에 제작하고 싶은 쇼츠 주제를 적고 생성 단추를 누르면 조립된 부탁 글이 나타납니다.

복사 단추를 누른 뒤 실제로 복사가 되었는지 확인합니다. 브라우저 보안 권한이나 실행 환경에 따라 복사 단추가 작동하지 않을 때는, 상자의 결과 글을 마우스로 직접 드래그하여 선택한 뒤 복사(Ctrl+C)하시면 됩니다.

복사한 문장을 챗GPT 대화창에 붙여넣어 본격적인 쇼츠 대본 답변을 받아보시면 됩니다.

💡 완성된 도우미로 만든 대본 요청 예시
도우미 웹페이지에서 만든 요청 글입니다: '스마트폰 사진 정리 팁을 주제로 40대 초보자가 이해하기 쉬운 40초 유튜브 쇼츠 대본을 작성해줘. 시선을 끄는 도입부 한 줄, 핵심 정리 세 문장, 마무리 한 줄로 구성해줘.' 이 조건에 맞춰 대본을 작성해줘.
⚠️ 제작 및 사용 시 꼭 지켜야 할 주의사항
  • 인공지능 대답 검토와 사실 확인: 인공지능이 생성한 출력 문장이나 코드는 때때로 부정확하거나 오해의 소지가 있을 수 있습니다. 생성된 대본의 정보나 코드가 의도대로 작동하는지 직접 열어서 확인하세요.
  • 민감한 개인정보 입력 금지 및 코드 점검: 파일 자체에 개인정보를 저장하지 마시고, 챗GPT에 프롬프트를 입력할 때도 주민등록번호, 계좌번호 등 민감한 개인정보를 입력하지 마세요. 또한 생성된 코드가 외부로 정보를 무단 전송하지 않는지 꼼꼼히 확인하세요.
  • 확인되지 않은 외부 스크립트 연결 금지: 웹페이지 코드를 다듬을 때 신뢰할 수 없는 외부 인터넷 주소(URL)에서 프로그램을 불러오도록 연결하지 마시고 순수 HTML과 자바스크립트로 구성하세요.
💻

컴퓨터와 스마트폰에서의 사용 환경 차이점

기기에 따라 파일을 다루고 대화창을 활용하는 방식에 차이가 있습니다.

컴퓨터 (PC / 노트북)
파일 저장 및 브라우저 실행

메모장을 활용해 HTML 파일을 내 컴퓨터에 직접 저장하고 브라우저로 바로 실행할 수 있어 화면 제작과 테스트에 적합합니다.

스마트폰 (모바일 앱)
대화 위주 프롬프트 활용

모바일에서는 별도 파일 저장보다 챗GPT 모바일 앱에서 직접 대화 형식으로 대본 질문을 주고받는 방식이 간편합니다.
