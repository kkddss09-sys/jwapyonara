💡 빈 칸을 누르면 0 ➔ 1 ➔ 빈 칸 순서로 바뀌고, 선택 후 아래 단추로도 넣을 수 있어요.

모든 문제는 컴퓨터가 직접 생성하며, 오직 하나의 정답만 존재하는 퍼즐입니다.

쉬는 김에 오늘 시세도 보고 가세요매일 오후 1~6시에 시세표가 올라와요
규칙 및 하는 법
  • 1. 3연속 금지: 한 줄(가로 또는 세로)에 같은 숫자가 세 개 연속으로 올 수 없습니다. (예: 000 금지, 111 금지)
  • 2. 개수 일치: 모든 가로줄과 세로줄에는 0과 1의 개수가 정확히 같아야 합니다. (쉬움 6×6은 각 3개씩, 보통 8×8은 각 4개씩, 어려움 10×10은 각 5개씩)
  • 3. 같은 줄 금지: 완성된 가로줄끼리는 서로 완전히 같은 모양이 될 수 없으며, 세로줄끼리도 마찬가지입니다.
  • 조작 방법: 빈 칸을 터치하면 0 ➔ 1 ➔ 빈 칸 순으로 바뀝니다. 또는 칸을 선택한 뒤 아래 키패드의 [0], [1], [지우기]를 누르거나 키보드 숫자 키를 입력할 수 있습니다.
  • 틀린 칸 확인: 판당 최대 3번까지 현재 잘못 들어간 칸이 있는지 즉시 검사합니다.
  • 힌트: 판당 최대 3번까지 풀리지 않는 빈 칸 하나의 정답을 논리적으로 채워줍니다.
  • 점수 계산: 기본 1,500점에서 걸린 시간(초)과 힌트 사용(1회당 100점)을 뺀 뒤 난이도 배수(쉬움 1배, 보통 2배, 어려움 3배)를 곱합니다.

이렇게 즐기세요

  1. 상단에서 원하는 난이도(쉬움, 보통, 어려움)를 고릅니다.
  2. 같은 숫자가 2개 붙어있는 곳(예: 00)을 찾아 양옆에 반대 숫자(1)를 먼저 채워보세요.
  3. 숫자 사이에 빈 칸이 끼어 있는 곳(예: 0_0)도 3연속이 되면 안 되므로 가운데에 반대 숫자가 들어갑니다.
  4. 한 줄에 0의 개수가 모두 찼다면 나머지 빈 칸은 생각할 필요 없이 모두 1입니다.

이럴 때 쓰면 좋아요

출퇴근길 지하철이나 버스 안, 잠들기 전 5분 동안 복잡한 생각 대신 깔끔한 숫자 논리로 뇌를 상쾌하게 깨우고 싶을 때 좋습니다.
