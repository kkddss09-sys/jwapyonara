쉬는 김에 오늘 시세도 보고 가세요매일 오후 1~6시에 시세표가 올라와요
하는 법
  • 게임 규칙: 가위는 보를 이기고, 바위는 가위를 이기며, 보는 바위를 이깁니다.
  • 연승 기록: 승리할 때마다 연승이 쌓이고, 패배하면 연승이 0으로 초기화됩니다(무승부는 연승이 유지됩니다).
  • 최고 연승: 달성한 최고 연승 기록은 브라우저에 안전하게 보관됩니다.
  • 이 게임은 좌표나라가 새로 만든 것입니다.

이렇게 즐기세요

  1. 화면 아래에 있는 세 개의 버튼 중 가위(✌️), 바위(✊), 보(✋) 가운데 하나를 터치하거나 클릭합니다.
  2. 버튼을 누르는 순간 컴퓨터도 동시에 무작위로 하나의 패를 꺼내며 즉시 승패와 결과 배너가 나타납니다.
  3. 승리할 때마다 현재 연승 카운트가 올라가며, 전적을 새로 시작하고 싶다면 '전적 초기화' 버튼을 눌러 처음부터 도전할 수 있습니다.

이럴 때 쓰면 좋아요

친구, 동료와 점심값 내기나 커피 쏘기, 당번 정하기 같은 일상적인 소소한 내기를 할 때 공정한 도구로 쓰기 좋습니다. 복잡한 앱을 내려받거나 회원가입할 필요 없이 브라우저에서 바로 열어 컴퓨터와 단판 승부를 겨루거나 연속 연승 신기록을 세우며 잠시 머리를 식히기에도 제격입니다. 무료하고 심심할 때 가볍게 운을 시험해 보세요.

가위바위보의 상성 규칙
가위는 보자기를 자르고, 바위는 가위를 깨뜨리며, 보자기는 바위를 감쌉니다. 세 가지 패가 서로 물고 물리는 완벽한 삼각 균형 구조를 이룹니다.
무승부와 연승 유지
컴퓨터와 내가 같은 패를 내어 비겼을 때는 패배로 처리되지 않으며, 지금까지 쌓아 올린 연승 기록이 그대로 유지된 채 다음 판으로 이어집니다.
로컬 전적 보관
달성한 최고 연승 기록은 기기 브라우저 내부 저장소에 안전하게 기억되므로 창을 닫았다가 나중에 다시 찾아와도 내 최고 기록이 유지됩니다.

자주 묻는 질문

컴퓨터가 제 패를 미리 보고 이기는 패를 내는 것은 아닌가요?

전혀 그렇지 않습니다. 본 게임의 컴퓨터는 사람이 버튼을 누르는 순간 세 가지 패 중 하나를 완전한 무작위(난수) 확률로 선택하도록 설계되어 있습니다. 사람이 내는 패를 사전에 읽거나 조작하는 알고리즘이 없으므로 완전히 공정한 확률 대결입니다.

연승 기록을 친구와 비교하거나 초기화할 수 있나요?

화면 상단에 현재 연승과 본인의 역대 최고 연승, 전체 승무패 전적이 실시간으로 표시됩니다. 화면 하단의 '전적 초기화' 버튼을 누르면 즉시 현재 판수와 연승이 0으로 비워져 깨끗한 상태에서 새 도전을 시작할 수 있습니다.

게임 이용 시 데이터가 소모되거나 로그인이 필요한가요?

별도의 로그인이나 회원가입 절차가 일절 없으며, 페이지를 한 번 불러온 뒤에는 모든 연산이 스마트폰이나 컴퓨터 기기 내부에서만 가볍게 실행됩니다. 외부 서버로 게임 기록을 전송하지 않으므로 언제 어디서든 안심하고 즐기실 수 있습니다.
