그림판

설치 없이 바로 그리고, 그린 그림을 내 기기에 저장하세요.

※ 그림은 내 기기 안에서만 그려지고 어디에도 전송되지 않습니다. 창을 닫으면 사라지니 필요한 그림은 저장하세요.

어떻게 쓰나요?
  • 펜 / 지우개: 그리고 싶은 도구를 골라 선을 그립니다. 지우개는 흰색으로 지웁니다.
  • 색상: 자주 쓰는 8가지 색을 누르거나, 무지개 단추에서 원하는 색을 직접 고를 수 있습니다.
  • 선 굵기: 슬라이더를 좌우로 움직여 가늘게(2px)부터 굵게(40px)까지 조절합니다.
  • 되돌리기: 실수로 잘못 그렸을 때 최대 20번까지 직전 상태로 되돌립니다.
  • 모두 지우기: 캔버스를 처음 흰 도화지 상태로 깨끗이 비웁니다.
  • 저장: '저장' 단추를 누르면 그린 그림이 흰 배경의 좌표나라-그림.png 파일로 내 기기에 다운로드됩니다.

이렇게 사용하세요

  1. 상단 툴바에서 '펜' 또는 '지우개' 모드를 선택합니다. 기본은 펜 모드로 시작합니다.
  2. 팔레트에서 원하는 기본 색상을 선택하거나, 무지개 색상 피커를 눌러 나만의 색상을 세밀하게 고릅니다.
  3. 굵기 슬라이더를 좌우로 움직여 가느다란 스케치선부터 두꺼운 채색선까지 브러시 크기를 조절합니다.
  4. 캔버스 도화지 위에서 마우스나 손가락으로 자유롭게 그림을 그린 뒤, 실수가 생기면 '되돌리기' 버튼을 누릅니다.
  5. 완성된 그림은 상단의 '저장' 버튼을 눌러 PNG 이미지 파일로 내 기기에 즉시 내려받습니다.

이럴 때 쓰면 좋아요

갑자기 떠오른 아이디어를 급하게 메모하거나 스케치하고 싶을 때, 무거운 그래픽 프로그램을 설치할 필요 없이 웹 브라우저에서 즉시 도화지를 열어 작업할 수 있습니다. 스마트폰이나 태블릿 터치펜으로 간단한 서명(싸인)을 만들어 이미지로 저장하거나, 아이들과 함께 가벼운 낙서 놀이를 즐길 때 유용하게 쓰입니다.

알아 두면 좋은 것

고해상도 디스플레이(Retina/DPR) 지원
기기의 화면 해상도 비율(Device Pixel Ratio)에 맞춰 캔버스 픽셀을 자동으로 보정하여 모바일이나 고해상도 모니터에서도 선이 흐려지지 않고 선명하게 그려집니다.
최대 20회 실행 취소(Undo)
스트로크 단위로 이전 캔버스 상태가 메모리에 보존되므로 잘못 그은 선이나 실수를 최대 20번까지 안전하게 되돌릴 수 있습니다.
기기 로컬 처리와 개인정보 보호
그림판의 모든 드로잉 데이터와 이미지 생성은 브라우저 캔버스 API를 통해 사용자 기기 내부에서만 처리되며 외부 서버로 전혀 전송되지 않습니다.

자주 묻는 질문

저장된 PNG 이미지의 배경은 투명한가요?

저장 버튼을 누르면 인쇄나 문서 삽입 시 보기 편하도록 깔끔한 흰색 배경 도화지 위에 그림이 합성되어 표준 PNG 포맷으로 안전하게 저장됩니다.

브라우저 창 크기를 바꾸면 그리던 그림이 지워지나요?

창 크기를 조절하거나 스마트폰 화면을 회전해도 기존에 그리던 그림 데이터가 임시 메모리에 유지되어 새 캔버스 비율에 맞게 자동으로 보존됩니다. 단, 웹 브라우저 탭을 완전히 닫거나 새로고침하면 초기화되므로 작업 도중 중요한 그림은 수시로 저장해 두시는 것이 좋습니다.

태블릿이나 스타일러스 펜의 필압(압력 감지)도 지원되나요?

본 그림판은 설치 없이 가장 빠르고 가볍게 스케치하는 표준 웹 포인터 이벤트 방식으로 동작하므로 압력 감지보다는 설정된 굵기 슬라이더 수치에 맞춰 일정한 굵기의 매끄러운 선을 제공합니다.
